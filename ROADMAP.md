# ROADMAP

## Phase 1: Standalone CRM Foundation
- Lead database
- Lead list view
- Lead detail page
- Notes, Tags, Tasks, Follow-up alerts
- CSV import/export
- Manual lead creation
- Basic duplicate detection

## Phase 2: Weekly Foreclosure Intake
- County source configuration
- Legal/public notice intake workflow
- Friday 12 p.m. scheduled run
- Raw notice storage, Notice parser, Lead creation from notices
- Address/legal description confidence status

## Phase 3: Contact Enrichment
- Manual enrichment workflow
- CyberBackgroundChecks-style lookup helper
- MyPlus Leads connector placeholder
- Enrichment status
- Contact confidence scoring
- Relatives/roommates fields

## Phase 4: CRM + Automation Integrations
- Google Sheets, Zapier webhook, Make.com webhook
- HubSpot/FUB/GoHighLevel export placeholders
- Custom API import/export
- Bulk lead actions

## Phase 5: Advanced Browser-Assisted Workflows
- Login-based connector framework
- Secure credential handling
- User-approved browser automation
- Error handling, Audit log, Compliance safeguards


## Phase 6: Next Steps
