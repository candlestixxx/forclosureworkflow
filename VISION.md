# VISION
**Project**: Foreclosure Lead Scrub + CRM Workflow Tool

## Ultimate Goal
Build a fast, easy-to-use real estate foreclosure lead automation tool. The system automatically collects weekly foreclosure notice-of-sale leads, enriches them with public record and contact data, organizes them into a simple CRM-style lead dashboard, and allows import/export or syncing with other CRM systems.

## Core Foundational Concepts
1. **Standalone Mode**: The tool works by itself as a foreclosure lead CRM, lead organizer, note tracker, task manager, and follow-up system.
2. **Integration Mode**: Connects with third-party tools, CRMs, browser systems, CSV files, APIs, and paid lead providers to import, enrich, update, and export foreclosure leads.
3. **Compliance First**: Build this tool only using lawful, permission-based, and terms-of-service-compliant methods. Do not bypass CAPTCHAs, login restrictions, paywalls, anti-bot systems, or website terms. Add compliance reminders for TCPA, CAN-SPAM, etc.
4. **Data Integrity**: Store the source of every piece of data. Track confidence scores. Avoid duplicates. Support manual correction of all imported data.

## User-Satisfaction Design
*   **UI Representation**: Every single planned or backend feature must be comprehensively wired to the frontend. Ensure robust coverage in the UI via explicit interactive forms, clear labels, distinct descriptions, and detailed tooltips.
*   **Fast and Simple**: The UI should be clean, fast, and simple.
